# Janine Bicca – Doces Finos

Premium luxury confectionery website built with Next.js, TypeScript, Tailwind CSS, and Sanity CMS.

## 🍫 Features

- **Editorial Minimalist Design**: Luxury aesthetic with creme/perolado backgrounds, rose gold accents, and dark chocolate brown text
- **Interactive Catalog**: Instant search with filter chips for categories, moods, and occasions
- **Quote Bag System**: Add products to bag and send pre-filled WhatsApp messages
- **Gift Box Builder**: Visual builder to create custom gift boxes (6/12/24 units)
- **Party Calculator**: Calculate recommended sweet quantities for events
- **Gallery**: "Doces na Mesa" showcase with real event photos
- **Tasting Kit**: Request degustação via WhatsApp form
- **FAQ**: Accordion-style frequently asked questions
- **Sanity CMS**: Headless CMS for easy content management

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ 
- npm or yarn
- Sanity account (for CMS)

### Installation

1. Clone the repository
2. Install dependencies:

```bash
npm install
```

3. Set up environment variables:

Create a \`.env.local\` file:

```
NEXT_PUBLIC_SANITY_PROJECT_ID=your_project_id
NEXT_PUBLIC_SANITY_DATASET=production
```

4. Run the development server:

```bash
npm run dev
```

5. Access the site at \`http://localhost:3000\`
6. Access Sanity Studio at \`http://localhost:3000/studio\`

## 🎨 Design

- **Colors**: Creme/perolado background, rose gold primary, dark chocolate brown text
- **Typography**: Playfair Display (serif) for headings, Geist (sans) for body
- **Layout**: Editorial minimalism with whitespace and macro food photography

## 📦 Tech Stack

- **Framework**: Next.js 16 with App Router
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **CMS**: Sanity.io
- **Animation**: Framer Motion
- **Components**: shadcn/ui
